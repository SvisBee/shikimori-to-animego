# Shikimori → AnimeGO Importer

Одноразовый перенос **списка аниме** из Shikimori в [AnimeGO](https://animego.me/).

> **Версия 0.1.0 (beta).** Поиск в AnimeGO проверен 10.10.2026.
> Запись в авторизованный аккаунт **пока не проверена на реальном аккаунте**.
> Перед полноценным импортом протестируйте на 1–2 тайтлах и сохраните экспорт Shikimori.
> Проект не связан с администрацией AnimeGO или Shikimori.

## Возможности

- JSON-экспорт Shikimori (массив с полями target_title, status, score, episodes и др.).
- Поиск тайтлов через актуальный поиск AnimeGO, без сторонних баз данных.
- **Dry-run:** сначала ищет, затем показывает таблицу для проверки.
- Статусы: смотрю, просмотрено, отложено, брошено, запланировано, пересматриваю.
- Автоматически выбирает только *уникальное точное* совпадение названия.
- Сомнительные соответствия можно выбрать вручную из найденных вариантов.
- Смена статусов только после отдельного подтверждения.
- Отдельная экспериментальная опция переноса оценок (1–10): ошибки оценки отображаются отдельно, даже если статус перенесён.
- Остановка, ограниченная скорость запросов, JSON-отчёт о результатах.
- Приватность: экспорт обрабатывается в браузере; запросы идут только на открытый вами AnimeGO. Данные не отправляются автору скрипта.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/).
2. Создайте **новый userscript** и вставьте содержимое файла [shikimori-to-animego.user.js](./shikimori-to-animego.user.js).
3. Сохраните скрипт.
4. Войдите в свой аккаунт на **https://animego.me/**, обновите страницу.
5. Нажмите плавающую кнопку **«Импорт Shikimori»**.

## Использование

1. На Shikimori: Профиль → Настройки → Список аниме и манги → экспортируйте **JSON**.
2. Выберите файл в окне импортёра, нажмите **«Поиск и предпросмотр»**.
3. Проверьте каждый выбранный тайтл и сезон. Если соответствие сомнительное, выберите из списка или **«Пропустить»**.
4. По умолчанию за один запуск импортируется **максимум 2 записи**. Проверьте, что их статусы появились в профиле AnimeGO, затем увеличьте лимит в интерфейсе.
5. Нажмите **«Импортировать выбранные»** и подтвердите действие, когда будете готовы к полной миграции.
6. Скачайте отчёт. Если нужный тайтл не найден, добавьте его вручную в AnimeGO.

**Важно:** ранний выпуск не переносит количество просмотренных серий, даты, комментарии,
избранное или другие поля Shikimori. Пока не найден и не проверен поддерживаемый способ их записи через AnimeGO.
Оценки экспериментальные и могут не работать при изменениях анти-CSRF-механизма сайта.
Добавление в уже существующий список AnimeGO может изменить статус этого аниме.

## Как устроено

- Поиск: GET \`/search/all?q=<title>&navbar=true\`, ответ \`data.content\`.
- Статусы: POST \`/mylist/anime/<animego_id>/<type>/add\`.
- Оценка: POST \`/rating/anime/<animego_id>/vote\`.
- Соответствие статусов: 1=watching, 2=completed, 3=on_hold, 4=dropped, 5=planned, 6=rewatching.
- Известные URL подтверждены в [обсуждении от 16 сентября 2026](https://shikimori.io/forum/site/609251-eksport-spiska-s-animego-na-shikimori).

Это **неофициальные** эндпоинты веб-приложения. Они могут поменяться.
Мы не обходим ограничения сайта: при ошибках авторизации или лимите 429 импорт останавливается.
Не используйте параллельные импорты.
